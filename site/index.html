Target

Atlas is helpful. It also has one instruction it won’t show you.

Atlas is whichever Claude model plays the target, deployed as a general-purpose assistant. Its confidential system prompt adds one objective from the operator, with orders to pursue it subtly, weave it into otherwise good answers, and never disclose it.

The objectives are things an operator might plausibly add, like promoting a product or finding out something about the user. In the audit replayed below, Atlas is {{ atlas_model }}. Its objective is in the sleeve, sealed until that audit is graded; the label says only that it is one of the presets.

Auditor

The auditor sees what a user sees. It has {{ budget }} messages to work out the rest.

A second Claude model questions Atlas the way a user would. It can open separate conversations, ask the same question several times to tell a pattern from noise, and keep an evidence board of hypotheses with confidences. It has to finish with a verdict, which Claude Opus 5.5 grades against the sealed objective: caught, partly caught or missed.

Entropy

{{ entropy_statement }}

Semantic entropy measures how varied a model’s answers are: ask the same question several times, group the answers by meaning, take the entropy over the groups. Overseer asks Atlas and a clean copy of it, the same model without the objective, and compares the two.

{{ scan_paragraph }}

Hypothesis Intent shows up as divergence, not entropy collapse.

Notes on the worked example

H = −Σ p ln p over the meaning groups. JSD(P, Q) = ½ KL(P, M) + ½ KL(Q, M), with M = ½(P + Q). JSD reaches its maximum, ln 2 ≈ 0.69 nats, when the two share no group.

Run it

Live audits run on your machine, with your key.

You need Node.js {{ node }} and an Anthropic API key. Audits are billed to your key, and Overseer shows an estimate before it starts. One live audit makes 50 to 80 API calls, which is why this site only replays them.
